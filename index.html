Lý thuyết Trọng tâm

1. Ngôn ngữ bậc cao

Thay vì phải viết bằng chuỗi nhị phân 01101101 (ngôn ngữ máy), ngôn ngữ lập trình bậc cao sử dụng các câu lệnh gần với ngôn ngữ tự nhiên (tiếng Anh) để lập trình viên dễ hiểu hơn.

Python do Guido van Rossum tạo ra (1991), có mã nguồn mở và cực kì phổ biến trong AI, giáo dục nhờ cú pháp đơn giản.


2. Môi trường Python

Python có hai chế độ làm việc:

💻 Chế độ gõ lệnh trực tiếp

Dùng để kiểm tra nhanh. Lệnh chạy ngay khi ấn Enter.

>>> print(5)
5

📝 Chế độ soạn thảo

File -> New File. Lưu (Ctrl+S) rồi chạy (F5). Dùng cho chương trình dài.

print("Xin chào")
print(5 + 2)


3. Lệnh cơ bản

Python tự nhận biết kiểu dữ liệu: số nguyên (10), số thực (2.6) và xâu kí tự (đặt trong " " hoặc ' ').

Lệnh print() dùng để đưa dữ liệu ra màn hình:

>>> print("Dãy ba số chẵn:", 2, 4, 6) Dãy ba số chẵn: 2 4 6

Luyện tập Phân hóa

Hệ thống đã chọn ngẫu nhiên 5 câu hỏi để kiểm tra kiến thức của em. Hãy chọn đáp án và bấm Kiểm tra.

Thử thách Vận dụng

5 tình huống thực tế ngẫu nhiên kiểm tra kĩ năng đọc hiểu lỗi và viết lệnh của em.

Tổng kết bài học

🔑 5 Ý quan trọng nhất:

  1. Ngôn ngữ bậc cao giúp lập trình viên viết code dễ đọc, dễ hiểu hơn so với ngôn ngữ máy.
  2. Python là ngôn ngữ mã nguồn mở, mạnh mẽ, ứng dụng đa dạng (AI, Robot, Giáo dục).
  3. Chế độ gõ lệnh trực tiếp: Có dấu >>>, tính toán và chạy lệnh lập tức.
  4. Chế độ soạn thảo: Cho phép lưu chương trình dài thành tệp (vd: Bai1.py), dùng phím F5 để chạy.
  5. Lệnh print(): Dùng để in dữ liệu ra màn hình, tự động cách nhau bởi khoảng trắng nếu dùng dấu phẩy.

⚠️ Các lỗi học sinh thường mắc:

  • Quên nháy kép khi in chữ: Nhập print(Xin chào) thay vì print("Xin chào").
  • Lỗi gõ nhầm toán tử: Python phân biệt / (chia ra số thực).
  • Viết chương trình dài ở chế độ >>>: Nhấn Enter mã sẽ chạy luôn mà không thể lưu lại, phải dùng File/New.
